# Changelog

All notable changes to FoF Weapon Rack Solver are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

## [1.2.0] - 2026-11-21

### Added

- Startup update check against the GitHub latest release, with current and new version shown and an option to open the download page.
- App version shown in the window title bar and in-app header.

## [1.1.1] - 2026-11-21

### Fixed

- Manual board entry no longer allows more than 4 swords, 4 spears, or 4 axes. Attempting a fifth of any type shows an error and leaves the board unchanged.
