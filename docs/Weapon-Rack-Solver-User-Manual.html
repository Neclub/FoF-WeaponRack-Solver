Weapon Rack Solver

User Manual

This guide explains how to install, configure, and use Weapon Rack Solver (WRc) — a Windows desktop app that builds EverQuest weapon-rack puzzles, finds a shortest solution, and can watch your EQ log for rack codes from chat.

2. What the app does

Weapon Rack Solver helps with the EverQuest “weapon rack” style puzzle:

  • There are 4 racks, each with 4 slots (top to bottom).
  • Weapons are Sword (Sw), Spear (Sp), and Axe (Ax).
  • A valid puzzle has exactly 4 of each weapon across all racks (12 weapons total; some slots empty).
  • The goal is to rearrange weapons so you end with one empty rack and three full mono racks (all Swords, all Spears, all Axes — one type per rack).
  • You may only move the bottom-most weapon on a rack onto another rack, and only if that destination is empty or its current bottom weapon is the same type (same-type stacking).

The app can:

  • Let you enter racks manually with mouse or keyboard.
  • Watch an EverQuest log file and fill racks from chat codes (for example R112`3).
  • Find a shortest move list and copy it to the clipboard.
  • Show a step-by-step demo animation and a codes board.
  • Optionally post puzzle/solve images (and a GIF) to a Discord webhook.

3. Requirements and setup

3.1 What you need

  • Windows 10 or 11
  • To run a pre-built binary: no extra install beyond the build\wrc.exe file and its settings next to the project.
  • To build from source: Visual Studio 2022 with the Desktop development with C++ workload (the cl compiler and resource compiler).

3.2 Build and run (from source)

  1. Open a Command Prompt or PowerShell in the project folder (the folder that contains start.bat and build.bat).
  2. Double-click start.bat, or run: 
    start.bat
  3. start.bat calls build.bat, compiles the app (and runs built-in tests), then launches build\wrc.exe.

You can also build without launching:

build.bat

On success you should see Build OK: build\wrc.exe.

Note: Settings are stored in wrc_settings.ini in the project root (the folder above build\). Window positions, hotkeys, log path, and Discord options are remembered between sessions.

4. Starting the app

  1. Run start.bat (build + launch) or open build\wrc.exe directly after a successful build.
  2. The main window title is Weapon Rack Solver.
  3. By default the window stays On top of other windows so you can keep it over EverQuest.

6. Entering a puzzle by hand

  1. Click a slot on the left Puzzle board to select it (selection highlight moves as you type or click buttons).
  2. Place weapons with the buttons or shortcuts:
    • Sword / Spear / Axe — put that weapon in the selected slot.
    • Gap — mark an empty slot (shown as a dash). Gaps count as empty for solving.
    • After placing, the selection advances to the next slot (and next rack when a rack is full).
  3. Use arrow keys to move the selection without changing a slot.
  4. Use rack shortcuts (1–4 by default) to jump to the top of that rack.
  5. Undo clears the current slot, or steps back one slot if the current slot is already empty.
  6. Clear empties the entire board and resets selection to rack 1, slot 1 (top).

Slots are ordered top → bottom within each rack. Rack order is 1–4 left to right.

Tip: Watch the Sw / Sp / Ax chips. Solve stays disabled until each shows 4/4.

7. Solving and reading results

  1. When counts are ready, click Solve or press the Solve shortcut (default Enter).
  2. While solving, the UI shows Solving - please wait...
  3. On success:
    • The right board shows the final mono layout.
    • The result panel shows move count and solve time (ms or seconds).
    • A paste string is built, for example: 
      R2Sw>R1, R3Ax>R4, R1Sp>R2
      Meaning: move Sword from rack 2 to rack 1, then Axe from 3 to 4, and so on.
    • The paste string is copied to the clipboard automatically.
    • If configured, Discord posting runs in the background.
  4. If the puzzle is already at the goal, you see Already solved (zero moves).
  5. If solve fails or counts are wrong, an error message appears in red (for example incomplete weapon counts).

7.2 Auto options

  • Auto solve — whenever the board becomes valid (4 swords, 4 spears, 4 axes), solve starts by itself. Useful with the log monitor.
  • Auto demo — after a successful solve with moves, open Demo automatically.
  • Auto codes — after a successful solve with moves, open Codes automatically.

8. Solution Demo window

Open with Demo on the result panel (or Auto demo).

  • Title: Solution demo.
  • Status line shows progress, for example Move 2/7 - R1Sw>R3.
  • The board animates each move (about 0.7 seconds per step while playing).
  • Controls:
    • Play / Pause — run or pause the animation.
    • Step — advance one move.
    • Restart — reset to the starting puzzle board.
    • Close — close the demo window.

Window size and position are remembered in settings.

9. Solution Codes window

Open with Codes (or Auto codes).

  • Shows every move as a chip like R2Sw>R1, color-tinted by weapon type.
  • Scroll if the list is long.
  • Useful for calling moves out one at a time in raid/guild chat.

10. Log monitor (EQ chat)

Instead of typing racks by hand, you can let the app read EverQuest log lines that contain rack codes.

10.1 One-time setup

  1. In EverQuest, enable logging so a character log file is written (typical path under your EQ install, for example ...\Logs\eqlog_CharacterName_server.txt).
  2. In Weapon Rack Solver, open Settings.
  3. Under EQ log file, click Browse... and select that log file.
  4. Check Enable log monitor.
  5. Confirm (or customize) Log search identifiers — defaults match common codes like R1…R4 with weapon digits (see section 15).
  6. Click Save and Close.

10.2 How live monitoring works

  • When enabled, the app opens the log at the end of the file and only reads new lines (status: Watching).
  • When a line contains one or more valid rack tokens, those racks are written onto the Puzzle board.
  • Status updates to something like Matched R212`3.
  • If Auto solve is on and all four racks together make a valid 4/4/4 puzzle, a solve starts automatically.
  • If the log rotates or shrinks, the monitor resets and continues (status notes rotation).
Important: Live monitor does not re-read old history until you use Scan recent. It only sees lines appended after monitoring started (or after the last read position).

11. Scan Recent

When a log path is set, the main window shows Scan recent.

  • Reads roughly the last 64 KB of the log file.
  • Parses any matching rack tokens and applies them to the board (latest match per rack wins as lines are processed).
  • Status becomes Scan found N match(es) or Scan - no matches in last 64KB.

Use this if someone already posted the racks before you turned on the monitor, or if you missed the live lines.

13. Discord webhook

Optional. After each successful solve, the app can POST attachments to a Discord incoming webhook.

  1. In Discord, create an Incoming Webhook for the channel you want.
  2. In Settings → Discord webhook..., paste the webhook URL.
  3. Choose what to send (any combination):
    • Puzzle — PNG of the starting board
    • Solve — PNG of the final board
    • Autosolve Video — GIF animating the moves (when there are moves)
    • Codes — PNG of the move codes layout
  4. Save and Close.

If the URL is empty, or all checkboxes are off, nothing is sent. Sends run on a background thread so the UI stays responsive.

Security: Treat the webhook URL like a password. Do not share it publicly. Anyone with the URL can post to that channel.

15. Puzzle rules (quick reference)

  • Input validity: exactly 4 Swords, 4 Spears, 4 Axes on the board (empty slots allowed).
  • Move: take the lowest (bottom) weapon on a rack and place it on another rack.
  • Stacking rule: destination must be empty, or its current bottom weapon must be the same type as the weapon you are moving.
  • Goal: one rack empty; the other three racks each filled with four of one weapon type (Sword rack, Spear rack, Axe rack — any order of racks).
  • Output format: R<src><Sw|Sp|Ax>>R<dst>, comma-separated for the full solution.

16. Chat code format

With default identifiers, a rack token is:

R<n><slot1><slot2><slot3><slot4>

where slots are top → bottom, and characters are:

CharacterMeaning
2Sword
3Spear
1Axe
`Empty / gap

Examples

R112`3
R2````
R2332`
R4`2`1

Multiple racks can appear in one chat line:

R1`123,R212`3.R31`23!R4``12

The parser finds each valid R# + four codes token. Tokens should not be glued to letters/digits/underscores immediately before them (so accidental mid-word matches are avoided). Common punctuation after a token (comma, period, quote, bracket, bang, space) is fine.

If your raid uses different digits or tags, change them under Settings → Log search identifiers so they match what people actually type.

18. Troubleshooting

ProblemWhat to try
Build fails: no compiler Install Visual Studio 2022 with Desktop development with C++, then run build.bat again.
Solve button stays disabled / errors about counts You need exactly four of each weapon. Check the Sw/Sp/Ax chips and fix typos or extra gaps.
Log monitor Idle / cannot open log Confirm the path in Settings, that EQ logging is on, and that the file exists. Re-enable the monitor after browsing to a new path (Save and Close).
No matches while watching Codes may have been posted before you started watching — click Scan recent. Also verify identifiers match the chat format.
Wrong rack filled from chat Adjust Rack tags / weapon characters in Settings. Use Reset identifiers if unsure.
Clipboard copy failed Another app may be locking the clipboard; try Copy again.
Discord nothing arrives Check webhook URL, that at least one attachment type is checked, and that the solve succeeded. See the session log for Discord skip/fail lines.
Window lost behind EQ Enable On top on the main window.
Shortcuts do nothing Click the main Weapon Rack Solver window so it has focus. Shortcuts are not global system hotkeys.

19. Typical raid workflow

  1. Launch Weapon Rack Solver; leave On top on.
  2. Point Settings at your EQ log; enable monitor; turn on Auto solve (and Auto demo/codes if you want).
  3. When racks are called in chat, the board fills. If Auto solve is on, the solution paste is ready immediately.
  4. Paste the move string into chat, or call moves from the Codes / Demo windows.
  5. If you missed the call, press Scan recent, then Solve if Auto solve is off.
